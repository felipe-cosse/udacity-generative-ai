This exercise explores one of the most impactful yet underappreciated aspects of working with LLMs: prompt engineering and its relationship to cost. This exercise demonstrates that how you prompt a model can matter just as much as which model you choose.

You'll systematically compare three prompting strategies (minimal, standard, premium) across three model tiers (mini, standard, premium), measuring quality, cost, and cost-effectiveness.

By the end of this exercise, you will be able to:

Design prompts at different specificity levels and understand the trade-offs between minimal, standard, and premium prompting approaches
Calculate true API costs on a per-request basis, accounting for both input and output tokens across different model tiers
Measure cost-effectiveness using the quality-per-dollar metric to identify optimal prompt-model combinations
Understand the diminishing returns curve where adding more detail to prompts stops improving results
Optimize for different scenarios: When to use minimal prompts (high volume, low stakes) vs premium prompts (low volume, high stakes)
Implement automated quality scoring for objective prompt comparison at scale
Make data-driven decisions about prompt complexity based on task requirements and budget constraints
