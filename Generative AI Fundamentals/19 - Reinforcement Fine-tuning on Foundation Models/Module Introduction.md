Welcome! In this module, we'll dive into the fascinating world of teaching Large Language Models new, specific skills. You'll learn about a powerful technique called GRPO (Generative Representational Preference Optimization) and see how it can be used to improve a model's ability to handle structured tasks. We'll start by teaching an LLM how to count and then you'll get hands-on experience by teaching one how to spell. Let's begin!

By the end of this module, you will be able to:

Explain how the GRPO technique can be used to teach an LLM a new skill.
Apply GRPO to a base model to improve its ability to count sequentially.
Implement the GRPO method to teach an LLM a different structured task: spelling.
