Welcome! In this module, you'll learn how to teach a Large Language Model (LLM) a new skill using a powerful technique called Supervised Fine-Tuning (SFT). We'll walk through a demonstration and then you'll get hands-on experience by completing an exercise where you teach an LLM to become a better speller. By the end, you'll have practical skills for customizing foundation models for specific tasks. Let's begin!

What You'll Learn
Apply Supervised Fine-Tuning (SFT) to teach a Large Language Model a new skill.
Prepare a dataset for fine-tuning an LLM on a specific task.
Implement the SFT process to improve a model's spelling ability.
Evaluate the performance of a fine-tuned model against its base version.
