In this hands-on exercise, you will build an image-moderation workflow with Gemini and Pydantic AI to enforce a workplace social media policy. The exercise uses a simulated TechCorp Inc. policy and synthetic images generated by Gemini to evaluate compliance. This workflow mirrors tasks in trust & safety, marketing approvals, HR compliance, and information security.

Prerequisites:
Access to a classroom Jupyter environment or local Python 3.10+ setup
Gemini API key with access to:
gemini-2.5-flash-lite (analysis)
gemini-2.5-flash-image-preview (image generation)
.env file in the parent directory of the notebook with:
GEMINI_API_KEY=YOUR_KEY
Python packages installed:
pydantic-ai, google-genai, python-dotenv, pillow, matplotlib, nest_asyncio
Internet access and billing enabled for Gemini usage (image generation may incur costs)
Objectives:
By the end of this exercise, you will be able to:

Load credentials from environment variables and validate access to Gemini
Define a Pydantic schema for moderation results, including policy violations
Create a Gemini-powered Agent with a system prompt and structured output
Generate test images from text scenarios and run the moderation pipeline
Interpret explanations and recommended actions for business use

Open the provided notebook in the classroom environment.
Create a .env file in the parent folder of the notebook with GEMINI_API_KEY set.
Verify environment and credentials
Run the setup cell. Confirm: - load_dotenv("../.env") returns True. - os.getenv("GEMINI_API_KEY") is present.
If a failure occurs:
Check the .env file path (parent directory of the notebook).
Ensure no extra spaces or quotes around the key.
Review policy categories
Understand the Enum PolicyViolationType: - none, unprofessional_attire, food_in_meeting_room, personal_items_on_desk, unorganized_workspace, confidential_info_visible
These categories are used for detection and reporting.
Complete the ModerationResult model
Replace the TODOs with: - is_compliant: bool = Field(description="True if the image follows company policy") - violations: List[PolicyViolationType] = Field(description="List of detected policy violations; empty if compliant")
Keep explanation and suggested_action as provided.
Create the Gemini Agent
Use gemini-2.5-flash-lite for analysis: - model: Gemini model configured for "gemini-2.5-flash-lite" - output_type: ModerationResult - system_prompt: COMPANY_POLICY_PROMPT - model_settings: the provided GoogleModelSettings with temperature=0.2 and seed=42
Ensure retries=3 remains to handle transient failures.
Add test scenarios for synthetic images
Extend test_scenarios by replacing the ellipsis with cases like: - "Client contract visible on laptop screen in a shared workspace" → confidential_info_visible - "Team in a meeting room with snack trays and drinks on the table" → food_in_meeting_room - "Desk covered with action figures, multiple framed photos, and souvenirs" → personal_items_on_desk - "Reception area with staff in shorts and flip-flops" → unprofessional_attire - "Cables, boxes, and papers piled around monitors" → unorganized_workspace
Generate images and run moderation
Execute the “Run the Analysis” cells.
The helper function: - Generates an image with gemini-2.5-flash-image-preview (with retries if blocked) - Feeds the image to the moderation agent via BinaryContent - Displays the image and prints the explanation and detected violations
Expect variability; generation and moderation are stochastic. seed helps but does not guarantee identical outputs.
Interpret outputs
If is_compliant=True and violations=[], the image appears safe to share.
If violations are present: - Read explanation for rationale tied to the policy. - Use suggested_action for guidance, such as "blur screen", "remove food", or "tidy workspace".
Compare detected violations to expected_moderation_result in each scenario to gauge behavior.
Optional enhancements
Expand scenarios to include borderline cases (e.g., a single coffee mug, a small personal photo).
